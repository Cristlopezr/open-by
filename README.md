# OpenBy

OpenBy is a mobile app that helps people keep track of products after they are opened and know
when they are expected to expire.

Users can scan a product's barcode, record when it was opened, and receive reminders based on its
recommended lifetime after opening. Personal inventory can be kept locally without requiring an
account.

## Core Ideas

- Barcode-first product entry
- Clear expiration tracking
- Local-first personal data
- Timely reminders
- A trusted shared product catalog

## Project Status

OpenBy is currently in the early stages of development.
